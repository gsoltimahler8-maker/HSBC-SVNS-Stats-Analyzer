# Security Policy

SVNS Stats Analyzer is an independent, unofficial analytics project.

## Reporting a security issue

Please do not publish sensitive vulnerability details, credentials, personal information, or private data in a public GitHub issue.

For a security-related report, contact:

`svnsstatsanalyzer@gmail.com`

Please include enough information to reproduce the issue, but do not include passwords, API keys, tokens, private account data, or third-party confidential information.

## Scope

Security reports may include issues involving:

- the public web application;
- repository configuration;
- dependency or build behavior;
- data validation behavior that could expose unintended information;
- PWA / service-worker behavior;
- accidental exposure of private development material.

Questions about match-data rights, licensing, source permissions, or video-use permissions are not security vulnerabilities. They should be handled separately through the project contact and the relevant rights/data owner.

## Public repository boundary

This repository is public. Any file committed to it should be treated as publicly accessible even when the application UI does not display or import that file.

Private correspondence, credentials, rights-uncertain raw data, and local-only working material must remain outside the public repository.
