## 3. v1.0完了後：対外連絡工程

### 目的

World RugbyおよびRugby Australiaに対し、公開スタッツの利用条件、項目定義、公式APIまたはデータフィードの有無を確認する。

この工程は「公認申請」ではなく、適切な利用方法と担当部署を確認するための初回問い合わせとする。

### 事前条件

以下を整備してから連絡する。

- 公開デモが安定して動作する
- プロジェクト概要ページがある
- 開発者情報が最低限確認できる
- 非公式・独立ツールであることを明記
- データソースと動画ソースを明記
- 利用規約
- プライバシーポリシー
- 免責事項
- 問い合わせ先
- 商用化前であることを明記
- 公式ロゴや公認表記を使用していない

### 初回問い合わせの内容

1. 公開スタッツを独立した非公式分析ツールで参照する場合の利用条件
2. 公開スタッツ各項目の定義
3. 研究・分析目的で利用可能な公式APIまたはデータフィードの有無
4. データ利用について問い合わせるべき担当部署
5. 現在の出典表示方法に問題がないか

### 初回問い合わせで避けること

- いきなり「データをください」と要求する
- 公認を求める
- ZIPや実行ファイルを添付する
- URL短縮サービスを使う
- 多数のリンクを送る
- GitHubリポジトリだけを送る
- 公式提携済みのような表現を使う

### 推奨リンク構成

```text
1. 公開デモ
2. プロジェクト概要
3. GitHubリポジトリ
```

初回メールでは、公開デモとプロジェクト概要を中心にし、GitHubは補助リンクとする。

### 連絡先候補

- World Rugby
- Rugby Australia

必要に応じて、一般問い合わせ窓口からデジタル、データ、競技分析担当への転送を依頼する。

### 返答がない場合

返答がなくても、v1.1以降の開発は停止しない。

返答がないことを、利用許諾や承認と解釈しない。
