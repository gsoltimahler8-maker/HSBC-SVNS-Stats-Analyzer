# SVNS Stats Analyzer プライバシーポリシー

文書版: 1.0  
制定日: 2026-07-26

## 1. 本アプリが直接取得する情報

Version1.0時点では、アカウント登録、ログイン、入力フォーム、独自アクセス解析を設けていません。

問い合わせメールを送信した場合、メールアドレス、表示名、本文、添付情報を取得します。

## 2. 利用目的

- 問い合わせへの回答
- データ訂正、動画リンク修正、表示不具合の調査
- 不正利用、迷惑行為、セキュリティ問題への対応
- 必要な範囲での運用記録と改善

## 3. 保存期間

問い合わせ情報は、対応、履歴確認、セキュリティ、法的義務のため合理的に必要な期間に限って保存し、不要になった情報は適切な方法で削除します。

## 4. 第三者への提供

法令に基づく場合、権利・安全を守るために必要な場合、または本人の同意がある場合を除き、問い合わせ情報を第三者へ販売・提供しません。メールの処理にはGoogleのサービスを利用します。

## 5. GitHub PagesとYouTube

- GitHub Pagesの利用時、GitHubがIPアドレス、端末・ブラウザ情報、Cookieその他の情報を自社方針に従って処理する場合があります。
- YouTube埋め込み動画を表示・再生すると、Googleへ通信情報が送信され、Cookie等が利用される場合があります。
- 埋め込みにはyoutube-nocookie.comを使用しますが、第三者への通信が完全になくなることを保証するものではありません。

## 6. ブラウザ・PWAキャッシュ

ブラウザは公開ファイルを一時保存する場合があります。本アプリはService Workerを使用し、公開アプリファイルや読み込み済みの公開データを端末へキャッシュする場合があります。これは基本的なオフライン再表示と更新管理のためであり、個人の行動履歴を識別・プロファイリングする目的では使用しません。ブラウザまたは端末のサイトデータ削除によりキャッシュを消去できます。

## 7. 照会・削除依頼

svnsstatsanalyzer@gmail.com へご連絡ください。本人確認や法令上の制約により、すべての依頼に応じられない場合があります。
