# SVNS Stats Analyzer 免責事項

文書版: 1.0  
制定日: 2026-07-26

## 1. 正確性と完全性

データは公開情報を手作業で確認・登録するため、転記ミス、更新遅延、欠損が生じる可能性があります。提供元ごとにスタッツ項目の定義・集計方法が異なる可能性があります。重要な判断では必ず公式記録と原典を確認してください。

## 2. 分析結果

平均値、相関、派生指標、可視化は競技分析を補助するもので、因果関係、将来の試合結果、選手・チームの能力を確定的に示すものではありません。

## 3. 高リスク判断

本アプリは賭博、投資、雇用、選考、医療、安全管理その他の高リスク判断を目的とした助言を提供しません。

## 4. 外部ページと動画

外部ページ、YouTube動画、埋め込み再生の可用性を保証しません。提供元の判断で変更、削除、制限される場合があります。

## 5. 損害

適用法で認められる最大限の範囲で、本アプリの利用、利用不能、表示内容、外部リンク、出力結果に起因する直接・間接の損害について責任を負いません。

## 6. 権利帰属

大会名、商標、試合データ、動画、画像その他の第三者コンテンツに関する権利は各権利者に帰属します。
