# SVNS Stats Analyzer 利用条件

文書版: 1.0  
制定日: 2026-07-26

## 1. サービスの目的

SVNS Stats Analyzerは、公開されているSVNSの試合情報、チームスタッツ、公式動画への導線を、検索・比較・検証しやすい形で整理する独立した非公式の情報提供・分析支援ツールです。

## 2. 非公式性

- World Rugby、HSBC、Rugby Australia、YouTubeその他の権利者による公式、公認、提携、スポンサー提供を受けたものではありません。
- 表示内容は公式試合記録、公式裁定、公式発表の代替ではありません。
- 大会名、組織名、商標は分析対象または出典の識別に使用します。

## 3. 許容される利用

- 個人的な試合分析、学習、研究、比較
- アプリが用意した出力機能の範囲内での非商用利用
- データ誤り、リンク切れ、表示不具合の報告

## 4. 禁止事項

- 不正アクセスまたは運用妨害
- アクセス、埋め込み、地域その他の技術的制限の回避
- 公式、公認、提携済みであると誤認させる利用
- 必要な権利を有しないコンテンツの再配布または商用利用
- 過度な大量・自動アクセス
- 法令または第三者サービスの利用条件に反する行為

## 5. 変更・停止

機能、表示、登録データ、利用条件は予告なく変更される場合があります。保守、障害、権利上の要請その他の理由により、全部または一部を停止・削除する場合があります。

## 6. 第三者サービス

GitHub Pages、YouTube、各データ・動画提供元には、それぞれの利用規約とプライバシーポリシーが適用されます。
