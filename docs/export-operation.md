# SVNS Stats Analyzer 出力機能運用

Version: 1.0  
Implemented: 2026-07-26

## CSV

Match Searchで設定した検索条件を反映し、現在表示対象となっている全試合をUTF-8 BOM付きCSVとして保存する。

Excel等で開いたときの日本語文字化けを抑えるため、先頭にBOMを付与する。

## Excel

外部パッケージを利用せず、ブラウザ内で.xlsxを生成する。

生成内容：

- 1シート
- ヘッダー行固定
- オートフィルター
- 文字列セルの折返し
- 数値セルを数値型として保存
- ソースURLを文字列として保存

大量データ対応はv1.1以降で再評価する。Version1.0の少数試合データを前提とする。

## PDF

PDFボタンはブラウザの印刷画面を開く。

手順：

1. Match Searchで試合を選択
2. PDFを押す
3. 新しい印刷用画面が開く
4. 印刷先で「PDFとして保存」を選択
5. 用紙サイズ、余白等を必要に応じて調整

ポップアップが拒否された場合、サイトのポップアップ許可を有効にする。

## 出力内容の注意

- 出力は公式記録の代替ではない
- sourceUrl、fetchedAt、dataCoverageLevelを確認する
- SAMPLE DATAを公式データとして扱わない
- 外部配布時は出典と非公式表示を削除しない
- 提供元の利用条件に反する再配布・商用利用を行わない
